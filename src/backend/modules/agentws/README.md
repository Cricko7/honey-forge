# WSS агента (модуль 08)

`/assets/stream` обслуживает небраузерного агента через TLS, Bearer token и
`resource-stream.v1`. Обработчик проверяет `agent.hello`, закрепляет за ловушкой
одно активное соединение, отправляет `agent.welcome`, принимает heartbeat,
выдаёт команды из модуля 06 и подтверждает результат после записи через его
сервис. Телеметрия обрабатывается отдельно от heartbeat и подтверждается
только после положительного результата `Gateway.Ingest`.

Границы `Gateway` потребляют будущие модули 05 и 07: аутентификация токена
с перечнем обязательных действий типа из каталога,
состояние ловушки, перевод offline и атомарный приём пачки событий. Методы
`Observe`, `Offline` и `Ingest` получают `connection_id`; реализация 05/07
должна отклонять устаревший идентификатор. `Ingest` возвращает положительный
ack только после PostgreSQL commit. Пока эти модули отсутствуют, `app.Open`
регистрирует маршрут, который возвращает 503. Для подключения нужно передать
`AgentGateway` и `AgentCommands` в `app.Config`.

Локальная фиксация событий, конфигурации и результатов, Redis-буфер и запуск
listeners относятся к отдельному процессу агента, которого пока нет в `src`.
Сетевой протокол и серверные границы проверяются TLS WebSocket тестами с
моками. Они не подтверждают долговечность локального буфера агента или
PostgreSQL commit модуля 07.

```powershell
go test ./modules/agentws
go test -tags=integration ./modules/agentws -count=1
```
