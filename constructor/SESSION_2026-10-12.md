# HoneyForge Constructor — сессия 2026-10-12

Отдельный Python-модуль «Конструктор цепочек ловушек» (встроим потом в панель HoneyForge).
Данные пока синтетические (fake). Реализация Фазы 1 роадмапа (`_hf_clone/ROADMAP.md`).

## Что сделано за день

### 1. Каркас модуля (backend FastAPI + frontend vanilla JS, без React)
- `backend/node_registry.py` — каталог **16 типов узлов** по 6 категориям (точки входа,
  сервисы-ловушки SSH/RDP/SMB/HTTP/Redis/SQL, endpoint-приманки АРМ/DC, honeytoken/документ,
  логика условие/задержка, реакции alert/SIEM) со схемами конфигурации для инспектора.
- `backend/models.py` — Pydantic v2: Node/Edge/Chain/Viewport + DTO.
- `backend/store.py` — in-memory + JSON-persistence (`data/chains.json`), сид 2 демо-цепочки,
  3 шаблона (dmz / internal / endpoint).
- `backend/validation.py` — правила: точка входа, совместимость портов, висячие узлы,
  конфликт TCP-портов, наличие реакции.
- `backend/simulator.py` — обход графа от точки входа, перенос украденных honeytoken-кредов
  дальше по цепочке, таймлайн kill-chain с маппингом на MITRE ATT&CK.
- `backend/app.py` — REST API + раздача статики.
- Фронт: бесконечная доска (pan/zoom к курсору, bezier-рёбра с типами портов flow/creds/
  token/loot), палитра+поиск+drag-n-drop, инспектор с динамич. формой, автосейв, тема SPI,
  симуляция с анимацией пути, валидация с подсветкой.

### 2. UI-переделка под пожелания
- Доска **на весь экран** (`canvas-wrap` fixed inset:0), все панели — **плавающие поверх**
  (стеклянные пилюли + blur, дизайн SPI [[reference_honeyforge_design]]).
- Палитра = **выезжающий drawer слева** по язычку «Узлы»; инспектор = drawer справа,
  сам открывается при выборе узла, уезжает по Escape/клику по фону.
- Снизу по центру — **сворачиваемый островок инструментов** (`#toolDock`, ручка-шеврон):
  Узлы · zoom −/%/+ · Вписать · **Авто-раскладка** (послойный BFS по attack-path) ·
  **Сетка** (снэп к GRID=26) · **Экспорт JSON**.
- Миникарту (квадратик справа снизу) **убрали**.

### 3. Боевой режим (enterprise) — главное за день
- `backend/runtime.py` (`RuntimeManager`): deploy/stop цепочки (узлы trap/*, endpoint/* →
  `running`), живой движок атак.
- Эндпоинты: `GET /api/chains/{id}/runtime`, `POST /api/chains/{id}/deploy {action}`,
  `GET /api/chains/{id}/stream` (SSE, `text/event-stream`).
- События SSE: `hello / attack_start / hop{edge_id,node_id,technique,source_ip,country,
  severity} / attack_end / kpi`.
- Фронт: кнопка **«Развернуть» → «В эфире»**, подписка через EventSource, **KPI-полоса**
  сверху (активные ловушки / атаки / события / источники / попытки входа), **живая лента**
  событий справа снизу (цвет по severity, IP+страна, ATT&CK).
- **Красные анимированные стрелки атаки** (WOW): `flashAttackEdge()` — бегущий красный
  пунктир на ребре + летящий «пакет» (SVG circle по `path.getPointAtLength`, rAF ~850мс);
  `pulseNode()` — пульсация узла под атакой; бейдж статуса ловушки на узле.

## Как запустить
```powershell
# из корня PythonProject (venv уже содержит fastapi+uvicorn+pydantic2)
powershell -File honeyforge\constructor\run.ps1
# или:
.\.venv\Scripts\python.exe -m uvicorn honeyforge.constructor.backend.app:app --port 8077 --app-dir .
```
Открыть **http://127.0.0.1:8077** → нажать «Развернуть» для боевого режима.

Остановить сервер:
```powershell
Get-Process python | Where-Object { $_.Path -like "*PythonProject*" } | Stop-Process
```
