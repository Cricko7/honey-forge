# HoneyForge — Frontend

**Панель управления платформой киберобмана (deception platform): разворачивай honeypot-ловушки, строй ложную инфраструктуру и наблюдай за атакующим в реальном времени.**

Моя зона — **весь фронтенд**: от дизайн-системы и анимаций до интеграции с Go-бэкендом по WebSocket и REST.

---

## 1. Как я это продаю (позиционирование)

> Это не «админка», а **премиальный SaaS-продукт уровня Linear / Vercel** в нише кибербезопасности.
> Оператор видит свою сеть ловушек как живую карту, ловит атакующего на каждом шаге его
> расследования и получает поток событий в реальном времени — в интерфейсе, который не стыдно
> показать на продажах enterprise-клиенту.

Три вещи, которые цепляют на демо:
1. **Живая карта сети** (drag-n-drop, подсветка атак в реальном времени).
2. **Real-time поток событий** по WebSocket — атаки «прилетают» на экран мгновенно.
3. **Продуманный премиум-дизайн** со светлой/тёмной темой, плавными переходами и фирменным брендом.

## 2. Что реализовано (экраны и функции)

| Экран | Что умеет |
|---|---|
| **Вход / Регистрация** | Авторизация оператора, регистрация админа + организации, cookie-сессия, демо-режим |
| **Дашборд** | KPI-карточки (активные ловушки, события 24ч, попытки входа, уникальные источники) с watermark-иконками; графики активности атак, распределение по типам событий, топ источников (IP); live-лента событий |
| **Конструктор сети** | Интерактивная карта на React Flow: узлы-ловушки + шлюз «Интернет», ручная раскладка с авто-сохранением, подсветка узлов и связей при атаке в реальном времени, мини-карта |
| **Добавление ловушки** | Каталог типов прямо в конструкторе, **автоподстановка случайного свободного порта**, **запрет дублей порта** с премиальным сообщением-подсказкой |
| **Ловушки / Детали** | Список ловушек, статус агента и рантайма, команды `start` / `stop` / `apply_config`, история команд |
| **События** | Журнал активности атакующих, декодирование payload / перехваченных кредов / страны, модалка деталей события |
| **Профили** | Создание и настройка конфигураций ловушек по типу из каталога |
| **Каталог типов** | Immutable-типы с версиями: описывают конфиг, события и действия |
| **Приглашения** | Премиум-страница: код приглашения с перевыпуском, доступ наблюдателя «только чтение», онбординг-шаги |
| **Запись сессий** | Просмотр записанных SSH-сессий высокоинтерактивных ловушек |

## 3. Дизайн-система (то, что делает «дорого»)

- **Фирменная палитра SPI** (Silver · Purple · Ivory) на CSS-переменных — одна система токенов для
  светлой и тёмной тем. Ключевой бренд-цвет **#6E56CF**.
- **Светлая / тёмная тема** с **плавным кросс-фейдом всего интерфейса** при переключении
  (не «щёлкает», как в сырых админках) — фирменный приём через временный класс на `<html>`.
- **Профессиональные микро-анимации**: плавный вход контента при навигации (`fadeInUp`),
  подъём карточек на hover, tactile-нажатие кнопок, анимированный переключатель темы
  (crossfade + rotate). Всё уважает системную настройку *prefers-reduced-motion*.
- **Собственный векторный логотип** (honeycomb-соты + искра-forge) в фирменном градиенте,
  адаптирующийся к теме, + SVG-favicon.
- **Контекстная шапка** премиум-уровня: показывает текущий раздел, организацию и живой
  статус потока.
- Иконки lucide-react, шрифты Inter / JetBrains Mono, компонентные классы
  (`card`, `btn`, `chip`, `input`) — единый визуальный язык.

## 4. Интеграция с бэкендом (реально работает, не макет)

- Говорит по **контракту OpenAPI** с Go-бэкендом: cookie-сессия, `X-CSRF-Token` + `Origin` на
  мутациях, `X-Expected-Revision` на удалении, `request_id` на POST.
- **WebSocket `/api/stream`** (субпротокол `dashboard-stream.v1`) — живой поток событий на всех
  экранах через единую подписку, держит кэш свежим.
- **Mock-слой** как фолбэк: фронт полностью работает в демо-режиме без бэкенда (удобно для
  показа и разработки), и мгновенно переключается на реальный fetch+WSS.
- Клиентская **валидация и UX-защита**: auth-гард (401 → /login), запрет дублей порта,
  блокировка команд для офлайн-агентов, понятные премиальные сообщения об ошибках.

## 5. Инженерная часть

- **Стек**: React + Vite + TypeScript (strict), React Router, TanStack Query, React Flow,
  Recharts, Tailwind CSS.
- **Архитектура API-слоя**: разделён на `client` / `hooks` / `cache` / `stream` —
  переиспользуемо и тестируемо.
- **Тесты**: модульные тесты API-клиента, стрима, кэша, авторизации и бизнес-хелперов.
- **Сборка в Docker**: SPA собирается в образ с nginx, отдаётся за единым origin с REST+WSS
  (TLS), прод-готовая конфигурация.
